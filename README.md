# 📝 Andrew Huycke – Resume

This repository contains the general version of my resume, written in **LaTeX** using the [FAANGPath Simple Template](https://www.overleaf.com/latex/templates/faangpath-simple-template/npsfpdqnxmbc).

## 📄 Files

- `Andrew_Huycke_Resume.tex`: Main LaTeX source file
- `resume.cls`: Class file from the FAANGPath template

## 🛠️ How to Compile

The compiled resume, in .pdf format, is already included in this repository, but if you wish to compile it locally:

1. Install a LaTeX distribution:
   - [TinyTeX](https://yihui.org/tinytex/) (This is what I use)
   - [TeX Live](https://www.tug.org/texlive/) (Linux)
   - [MacTeX](https://tug.org/mactex/) (MacOS)
   - [MiKTeX](https://miktex.org/) (Windows)

2. Compile with `xelatex`:

   ```bash
   xelatex Andrew_Huycke_Resume.tex
